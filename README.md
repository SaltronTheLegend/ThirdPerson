# 🎮 Third Person Game Prototype (Unreal Engine)

A third-person character controller prototype built using Unreal Engine, focusing on player movement, camera systems, and core gameplay mechanics.

---

## 🚀 Overview

This project demonstrates the implementation of a third-person character system, including player locomotion, camera control, and real-time input handling using Unreal Engine.

It serves as a foundation for building third-person action or adventure games.

---

## 🛠️ Tech Stack

- Unreal Engine
- C++ / Blueprints (based on implementation)
- Unreal Gameplay Framework (Character, Controller, Camera)

---

## 🎯 Features

- Third-person character movement (walk, run, jump)
- Camera follow system (over-the-shoulder / free look)
- Input handling using Unreal’s input system
- Character rotation aligned with camera direction
- Smooth movement and animation transitions
- Frame-based updates using Tick system

---

## 🧠 Key Learnings

- Understanding Unreal’s Character vs Pawn system
- Implementing camera systems using Spring Arm + Camera components
- Handling player input and movement logic
- Working with rotation, direction vectors, and camera alignment
- Structuring gameplay systems using Unreal’s architecture

---

## 🎮 Controls

| Action        | Input        |
|--------------|-------------|
| Move         | WASD        |
| Look Around  | Mouse       |
| Jump         | Space       |

## ⚙️ Project Structure

- `Source/` → Core gameplay logic (C++)
